⌘PROJECT 06

Telegram AI Food Ordering Assistant

A Telegram-based AI assistant designed to help customers ask questions and work through a food order for Tasty and Sweet Food Place.

  • n8n
  • Telegram
  • Groq LLM
  • HTML extraction
  • Conversational AI
Repository placeholder ↗

Problem

Food businesses may need to respond to customer enquiries and collect complete order details consistently, without making unsupported promises about prices or payments.

Solution

An n8n workflow connects Telegram messages to an AI agent powered by Groq, then sends the agent's reply back to the customer in Telegram. The agent's instructions guide it to collect order details, summarize an order for customer approval, use only confirmed business information, and refer uncertain questions to the business owner.

Implemented workflow components

  • Receive incoming Telegram messages.
  • Generate a conversational response with the AI agent and Groq chat model.
  • Connect a memory node to support conversational context.
  • Send the generated response back to the same Telegram chat.
  • A separate manual-trigger branch fetches a website and extracts its main page content; this branch is not connected to the Telegram agent in the supplied workflow.

Intended customer journey

Customer message → AI-guided order conversation → order summary and customer approval → payment instructions and follow-up, with business-owner review where needed.

The supplied workflow currently shows the Telegram conversation path and a separate website-extraction path. Payment verification, owner notifications, and order-status updates are described in the agent instructions but are not shown as connected automation nodes in this version.
